How it works without sending the secret:
Both your app and the server share the same secret key (exchanged once at registration). Each side independently computes HMAC-SHA1(secret, floor(time / 30)) and truncates the result to 6 digits. Because they use the same secret and the same timestamp, they arrive at the same code — the secret never travels over the network after the initial setup.
